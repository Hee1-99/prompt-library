# 복붙 AI 업무 라이브러리

사업, 업무, 학습에 바로 복사해서 쓸 수 있는 한국어 AI 프롬프트 1000개 라이브러리입니다.  
GitHub Pages에 그대로 올릴 수 있는 정적 웹앱이며, 별도 빌드나 서버가 필요 없습니다.

## 구성

- `index.html`: 웹앱 진입점
- `styles.css`: 반응형 UI 스타일
- `src/catalog.js`: 40개 산업/사용자군 x 25개 업무 유형 = 1000개 프롬프트 생성 데이터
- `src/app.js`: 검색, 필터, 정렬, 변수 입력, 복사 기능

## 사용 방법

브라우저에서 `index.html`을 열면 바로 사용할 수 있습니다.

1. 검색창에 필요한 키워드를 입력합니다.
2. 대상, 산업군/분야, 업무 유형, 태그로 좁힙니다.
3. `복사`를 눌러 원본 프롬프트를 복사합니다.
4. `변수 입력`을 누르면 `{목표}`, `{대상}` 같은 변수를 내 상황에 맞게 채울 수 있습니다.

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소로 올립니다.
2. 저장소 Settings로 이동합니다.
3. Pages에서 Source를 `Deploy from a branch`로 선택합니다.
4. Branch를 `main` / `/root`로 설정합니다.
5. 생성된 Pages URL을 README와 프로필에 연결합니다.
